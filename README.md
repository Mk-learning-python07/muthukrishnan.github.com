## 🔍 About Me

This website introduces you to my background, education, and career. The About Me section covers who I am, my toolkit, and what I'm chasing now.

## 💼 Professional Journey

The Professional Journey section walks through my roles at ExxonMobil - offshore process engineering in Newfoundland, and remote process surveillance across global upstream assets before that - along with the projects, tags, and outcomes tied to each.

## 🔬 Research

The Research section covers my current M.Sc. work: optimizing Pressure Vacuum Swing Adsorption (PVSA) cycles for post-combustion carbon capture using CALF-20 MOF structured contactors, under Prof. Arvind Rajendran at the University of Alberta. 🧠

## 🧪 Apps & Tools

A running list of small tools I've built on the side - an interactive adsorption isotherm and IAST explorer, a scrolling visual breakdown of a research paper, and a personal reference on multi-objective optimization with pymoo's NSGA-II. Try them directly in the browser, no install needed.

## 🛠️ Technologies Used

* **Jekyll** 🛠️ - This site is powered by Jekyll, a static site generator that makes creating websites easy and efficient.
* **Custom design system** 🎨 - A hand-built theme (not a stock Jekyll theme) with a light/dark mode toggle and a small component library for cards, timelines, and stats.
* **HTML/CSS** 🔌 - For the core structure and styling of the website.
* **JavaScript** 💻 - For the sticky header, theme toggle, scroll reveal, and other interactive elements.
* **Claude** 🤖 - Claude helped design the site's theme, curate content, and provided technical support throughout development.
* **GitHub Pages** 🌐 - Hosted via GitHub Pages, making the website easily accessible and publicly available.
* **Font Awesome** 🎨 - Used for icons throughout the site, including social links in the footer.
* **Google Analytics** 📊 - Used to track website traffic and user interactions, providing insights into how the site is being used to improve the user experience.
